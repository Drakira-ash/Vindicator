# 被拦截敌人应停止移动

## 验收标准

- [ ] 怪物被友军拦截后不再继续移动
  > 原话：“BUG：怪物被拦截应该停下来”
- [ ] 敌人被拦截时，若拦截我的人不在攻击范围内，进入 Idle
  > 原话：“拦截我的人是否在我的攻击范围内-->是：攻击/否：Idle”
- [ ] 敌人被拦截时，若拦截我的人进入攻击范围，进入攻击
  > 原话：“拦截我的人是否在我的攻击范围内-->是：攻击/否：Idle”
- [ ] 攻击目标丢失后回到 Idle
  > 原话：“攻击-->单位丢失：Idle”
- [ ] 任何状态下生命值为 0 进入死亡
  > 原话：“任何状态-->生命值为0：死亡”
- [ ] 状态机落盘，并核查当前实现是否满足
  > 原话：“状态机详情如上所示，请落盘并核查目前的实现是否满足上述需求”

# 公民 / 废墟 / 开发者模式

## 验收标准

**开发者模式**

- [ ] 【开发者模式】运行时按 F2 可开/关所有单位的检测范围球；Inspector 的 `startEnabled` 决定初始状态。
  > 原话：“可以开关的 针对所有单位的 检测范围的可视化 用一个半透明的球体来表示”
- [ ] 【开发者模式】球体半径与单位感知范围一致：敌人 7、战士 10、公民 2；箭塔显示攻击范围（约 20.6）。
- [ ] 【开发者模式】球体半透明、无 Collider、不参与索敌/贴地探测，开启后控制台 0 error。
- [ ] 【开发者模式】关闭后球体全部销毁，无残留对象；重复开关不泄漏。

**公民**

- [ ] 【公民】公民模板数值与需求完全一致：血量 30、攻击 2、移速 2、攻击间隔 2、攻击范围 1.5、感知范围 2、生产力 100。
  > 原话：“血量 30 / 攻击 2 / 移速 2 / 攻击间隔 2 / 攻击范围 1.5 / 感知范围 2 / 生产力 100”
- [ ] 【公民】Idle 时先找建筑（废墟优先），再找敌人；都没有则原地 Idle。
  > 原话：“Idle-》感知范围内是否有建筑-》是-》是否废弃-》是-》修建 / 否-》进驻-》销毁；否-》范围内是否有敌人-》是-》攻击 / 否-》Idle”
- [ ] 【公民】废墟在感知内 → 走到交互距离 → 按 100 点/秒推进建造条。
- [ ] 【公民】已建成建筑在感知内 → 走进并销毁自己（已确认的字面行为）。
- [ ] 【公民】敌人在感知内且无建筑 → 追击、进入攻击范围后停下攻击。
- [ ] 【公民】生命值归零 → Brain 禁用、停止移动、不再推进建造条。
  > 原话：“任何状态-》生命值归零-》死亡”

**废墟 / 建筑**

- [ ] 【废墟】建造条上限 500；公民连续修建 5 秒完成。
  > 原话：“建造条 500”“每个塔位身边出现一个公民 5S 修建好塔”
- [ ] 【废墟】修建中断（公民死亡/离开/目标失效）后进度保留，重新修建从原值继续。
  > 原话：“如果建造过程中被打断，保持建造条”
- [ ] 【废墟】废墟阶段不在 `UnitRegistry`，敌人索敌/溅射/拦截都选不中它。
  > 原话：“废弃不能被敌人打”
- [ ] 【废墟】建成后启用 `UnitHealth`、炮台 AI 与投射物攻击，可被敌人攻击；血量 500。
- [ ] 【废墟】建造条在废墟阶段显示、建成后隐藏；血条相反。

**测试场景**

- [ ] 【测试场景】`Tools/Unit/Create Building Test Scene` 可重复执行，不产生重复对象。
- [ ] 【测试场景】场景中两个塔位变为废墟，旁边各一个公民；4 战士、30 敌人、巡逻点保持不变。
  > 原话：“目前存在的两个塔位都变为废弃塔…每个塔位身边出现一个公民”“其他设定不变”
- [ ] 【测试场景】PlayMode 中两座塔在约 5 秒后建成并开始攻击；控制台无 `MissingReferenceException`。
- [ ] 【测试场景】`MVP.unity` 未被修改，用户未提交的 `groundMask` 改动保留。

**工程验证**

- [ ] 【工程验证】`python .agent/scripts/agent.py index` + `validate`：0 error。
- [ ] 【工程验证】Unity 编译验证 pass（编辑器证据 + adopt）。
- [ ] 【工程验证】EditMode 测试 pass：新增建筑/公民状态机测试 + 原有用例不回归。
- [ ] 【工程验证】新增 `.cs`/`.prefab`/`.asset` 均有配对 `.meta`。

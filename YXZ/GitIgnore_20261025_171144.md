# Git 上传准备说明（20261025_171144）

## 本次新增
- 新建项目根目录 `.gitignore`（Unity + Visual Studio 常用忽略项）。

## 主要忽略内容
- Unity 生成目录：`Library/`、`Temp/`、`Obj/`、`Build/`、`Builds/`、`Logs/`、`UserSettings/`。
- IDE/工程临时文件：`.vs/`、`*.csproj`、`*.sln`、`*.user` 等。
- 打包产物：`*.apk`、`*.aab`、`*.unitypackage`。
- Addressables 生成目录：`ServerData/`、`StreamingAssets/aa/`。

## 作用
- 避免上传可再生缓存与本机配置。
- 减少仓库体积并降低合并冲突概率。

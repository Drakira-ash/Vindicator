# TD Workflow Test 迭代说明（20261025_164129）

## 本版本新增功能
1. 新增 `Tools/TD Workflow/Create TD Workflow Test Scene`：一键创建 `Assets/Scenes/TD_Workflow_Test.unity`。
2. 新增 `Tools/TD Workflow/Update Selected Road` 与 Inspector 按钮：手动刷新道路网格（无需 Play Mode）。
3. 新增 `TDRoadSplineAuthoring`：基于 Splines 生成平坦带状道路网格（RoadVisual）并同步 MeshCollider。
4. 新增可编辑白盒结构：
   - `Route/SplineSource`（样条控制点可拖拽）
   - `Route/RoadVisual`（生成网格）
   - `EditableGeometry/Cliff`（ProBuilder 可编辑）
   - `EditableGeometry/Platform`（ProBuilder 可编辑，顶面初始 Y=1）
   - `Landmarks/TavernPlaceholder`
   - `References/CharacterReference`
   - `References/TowerFootprint`（2×2 米）
5. 新增俯视主相机自动计算：根据场景可见范围计算 orthographicSize，确保比例参照清晰。

## 既有功能列表
1. 现有 `SampleScene` 与模板资源保持不变。
2. URP 渲染管线配置保持不变。
3. 已有包依赖保持不变，仅复用已安装的 ProBuilder 与 Splines。

## 各文件职能概览
- `Assets/Script/TDWorkflow/TDRoadSplineAuthoring.cs`
  - 保存道路引用与参数（样条源、RoadVisual、宽度、采样密度）。
  - 执行道路网格重建（只改 RoadVisual 自有 Mesh）。
- `Assets/Script/TDWorkflow/Editor/TDWorkflowEditorTools.cs`
  - 提供菜单入口：创建测试场景、更新选中道路。
  - 创建 ProBuilder 白盒对象、共享材质、静态碰撞体、俯视主相机。
  - 提供 `TDRoadSplineAuthoring` 自定义 Inspector 按钮。

## 操作说明
1. 打开菜单 `Tools/TD Workflow/Create TD Workflow Test Scene`。
2. 场景创建后，展开 `Route`，选中 `SplineSource`，在 Scene 里拖动样条控制点。
3. 选中 `Route`（或包含 `TDRoadSplineAuthoring` 的对象）：
   - 菜单 `Tools/TD Workflow/Update Selected Road`，或
   - Inspector 点击 `Update Road Mesh`。
4. ProBuilder 编辑入口：
   - 选中 `EditableGeometry/Cliff` 或 `EditableGeometry/Platform`。
   - 使用 ProBuilder 的面/边/点编辑工具进行手动精修。
5. 不应直接手改对象：
   - `Route/RoadVisual` 顶点不作为编辑源，应以 `SplineSource` 为唯一道路编辑依据。

## 参数含义
- `Spline Source`：道路形状来源（样条控制点对象）。
- `Road Visual`：道路网格承载对象（生成结果）。
- `Road Renderer`：道路材质显示组件。
- `Road Collider`：道路物理碰撞体组件。
- `Road Width`：道路总宽度（米），默认 3。
- `Samples Per Meter`：每米采样数，值越大转弯越平滑、网格更密。

## 规范对齐说明
- 使用 1 单位 = 1 米。
- 初始道路宽度 3 米，样条控制点初始化在整数坐标。
- 平台顶面初始高度为 Y=1（通过顶面中心枢轴与几何高度定义保证）。
- Cliff/Platform 维持 `localScale = (1,1,1)`，不靠缩放伪造尺寸。

## 当前限制
1. 首版仅支持同一高度道路，不含交叉口、桥梁与自动贴地。
2. 急转或切线异常时会提示局部宽度可能失真。
3. 未实现玩法系统（寻路、战斗、经济、联机等）。

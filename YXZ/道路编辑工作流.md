# 塔防道路编辑工作流

> 本文档对应 `Assets/Script/TDWorkflow/` 下的路网系统，在 Unity 6000.0.39f1 上验证通过。

---

## 一、这次做了什么

之前道路是用 ProBuilder 的 `PolyShape` 一块块手拼的：宽窄不一、拐角是硬折线、改一次要重新摆点。这次换成一整套**数据驱动**的路网工具：

| 能力 | 说明 |
|---|---|
| **场景视图直接画路** | 选中 `Road` 对象后，在 Scene 视图点地面就能放路点、拖拽移动 |
| **三种吸附** | 格点吸附、已有节点吸附、角度吸附，可单独开关 |
| **自动转弯** | 拐点自动生成圆滑贝塞尔弯道，弯道缓急由参数控制 |
| **岔道 / 路口** | 一个节点连出三条以上边就是路口，自动生成补片填平缺口 |
| **一键重建网格** | 整张路网合并成一个 Mesh + MeshCollider，改完立刻看得到 |
| **旧路导入** | 把原来的 6 块 PolyShape 自动转成可编辑路网 |

核心是三块：

```
TDRoadNetwork      路网数据（节点 + 无向边），挂在 TD_Whitebox/Road 上
TDRoadMeshBuilder  把图算成网格（纯几何，运行时可调用）
Editor/*           场景视图交互、参数面板、旧路导入
```

**没有**改动的部分：敌人寻路、NavMesh、塔的攻击判定都不在本次范围。`MVP.unity` 完全没动，所有改动和验证都在 `RoadWorkflow_Test.unity`。

## 二、快速上手

### 第 1 步：准备对象

1. 打开 `Assets/Scenes/RoadWorkflow_Test.unity`
2. 选中层级里的 `TD_Whitebox/Road`
3. 如果它身上没有 `TDRoadNetwork` 组件：菜单 **Tools ▸ TD Road ▸ 道路编辑器窗口**，点 **「创建/选中 Road 对象」**

### 第 2 步：开始画路

1. 保持 `Road` 选中，鼠标移到 Scene 视图
2. **左键点地面** → 放下第一个路点，这条路开始
3. 继续点 → 每点一下延伸一段
4. 想拐弯就直接点下一个位置，弯道是自动的
5. 按 **Esc** 或 **右键** 结束这条路

### 第 3 步：加岔道

**结束上一条路（Esc）后，左键点已有路上的任意节点** → 从那个点开始一条新路，再点地面延伸出去。
点上以后这个节点就自动变成路口，系统会生成补片把三条路缝在一起。

## 三、场景视图操作速查

| 操作 | 效果 |
|---|---|
| **左键点地面** | 在当前这条路末尾追加一个路点 |
| **左键点已有节点** | 把当前这条路连过去并结束（没有进行中的路时，则是从该点起一条新路） |
| **拖拽节点** | 移动节点，路面实时跟着变 |
| **Ctrl + 左键点节点** | 删除节点及它连着的所有边 |
| **Ctrl + 左键点路面** | 删除被点中的那条边（两端节点保留） |
| **Esc / 右键** | 结束当前这条路 |
| **滚轮 / 中键 / 右键拖拽** | 正常交给 Unity 的视图操作，不会被拦截 |

节点颜色含义：

| 颜色 | 含义 |
|---|---|
| 🟢 绿色 | 端点（只连 1 条路）—— 通常是入口或出口 |
| ⚪ 白色 | 转弯点（连 2 条路） |
| 🟠 橙色 | **路口**（连 3 条及以上） |
| 🔵 青色 | 当前鼠标吸附到的目标节点 |

## 四、参数面板

**Tools ▸ TD Road ▸ 道路编辑器窗口**

### 吸附

| 参数 | 默认 | 说明 |
|---|---|---|
| 格点吸附 | 开 | 路点坐标吸附到格点 |
| 格点大小 | 0.5 m | 格子边长 |
| 节点吸附 | 开 | 鼠标靠近已有节点时吸过去并复用该节点（岔道就靠它） |
| 吸附半径 | 2 m | 多大范围内算“靠近” |
| 角度吸附 | 开 | 与上一个路点的连线方向吸附到固定角度 |
| 角度步长 | 15° | 角度吸附的粒度 |

三个吸附按 **节点 → 角度 → 格点** 的优先级依次生效，后面的不会破坏前面已吸附的结果。

### 生成参数（存在路网组件上，跟随场景）

| 参数 | 默认 | 说明 |
|---|---|---|
| defaultWidth | 5 m | 路宽，和旧路实测宽度一致 |
| cornerSmoothness | 0.35 | 弯道切线长度占边长比例，越大转弯越平缓、越“胖” |
| samplesPerMeter | 1 | 每米采样点数，越大网格越密、转弯越圆滑 |
| roadHeight | 0.02 m | 路面离地高度，和旧路一致 |
| roadMaterial | Road_Mat | 路面材质 |
| autoRebuild | 开 | 改参数后自动重建 |

单个边也可以有自己的宽度（`Edge.width`），留 0 就用默认宽度。

## 五、生成规则（为什么长这样）

### 转弯是怎么变圆的

每条边生成一条**两节点的三次贝塞尔**。节点处的切线方向这样定：

- **连 2 条路的节点**：取两条相邻边方向的**角平分线**
- **端点 / 路口**：沿边方向直出

因为相邻两条边在共享节点上算出的是同一个切线方向，所以两段路面在接缝处的顶点位置和朝向完全一致，**没有裂缝**。

### 路口是怎么填平的

路口（≥3 条边）处所有边都终止于节点中心。把连接的边按角度排序，每对相邻边之间：

1. 找到两条路各自的“靠缺口那一侧”的边缘
2. 把这两条边缘延长直到相交，得到一个楔形缺口
3. 用两个三角形把缺口补上

补片比路面**高 2 mm**，所以和路面重叠的地方不会闪烁（z-fighting）。夹角越尖，补片伸得越远；伸得太夸张时会截断在 3 倍路宽处。

### 网格

整张路网（所有边 + 所有路口补片）合并成**一个 Mesh**，挂在 `Road/RoadMesh` 下，同时作为 `MeshCollider`。

## 六、从旧路导入

菜单 **Tools ▸ TD Road ▸ 从旧路导入（Road_OldBackup）**，或窗口里的同名按钮。

做法：

1. 读取 `TD_Whitebox/Road_OldBackup` 下每块 ProBuilder 几何体的顶点
2. 顶点相距 0.6 m 以内视为**两块路相接** → 在共享处生成一个连接节点
3. 每块几何体沿它的主轴把连接点串成折线
4. 末端离所有连接点超过 4 m 的，自动补一个端点

**注意：这是启发性近似。** 手绘的多边形（比如原来那块 8 边形、9 边形的不规则块）无法完全还原，导入后形状需要人工微调。它给的是**拓扑正确的起点**，不是最终结果。

导入会清空当前路网 —— 可以 Ctrl+Z 撤销。

## 七、运行时 API（给后续寻路用）

`TDRoadNetwork` 上的公开方法：

```csharp
// 图查询
network.GetDegree(nodeId)                       // 度数：1 端点 / 2 转弯 / ≥3 路口
network.IsJunction(nodeId)
network.GetNeighbors(nodeId, results)
network.GetEndpointNodeIds(results)             // 所有入口/出口
network.TryGetNodePath(fromId, toId, path)      // BFS 最短路径

// 取某条边的中心线（本地坐标，逐点采样）
var edge = network.Edges[0];
var spline = TDRoadMeshBuilder.BuildEdgeSpline(network, edge);
Vector3 point = spline.EvaluatePosition(0.5f);
```

节点坐标是 **Road 对象的本地空间**，转换成世界坐标用 `network.transform.TransformPoint(node.position)`。

## 八、常见问题

**Q：点了地面没反应？**
A：确认 ① `Road` 对象被选中；② Scene 视图里鼠标不在 UI 面板上；③ 没有在按 Alt（Alt+左键是视图环绕，会被放行）。另外工具栏左上角处于 Hand 工具时不影响，画路不受 Unity 自带工具影响。

**Q：节点吸不上？**
A：检查窗口里「节点吸附」是否打开、吸附半径是否够大。视角拉得太远时像素距离大，也需要更大的世界半径。

**Q：路口有明显缝隙 / 有闪烁？**
A：缝隙通常是夹角非常尖（<30°）时的截断造成的，把那条支路的角度调整一下；闪烁说明补片没生效，点一次「重建道路网格」。

**Q：重新打开场景路面不见了？**
A：路面网格是独立资源，存在 `Assets/TDWorkflow/Generated/<场景名>_Road.asset`。确认这个文件还在，并且 `Road/RoadMesh` 的 MeshFilter 指向它。不要关掉窗口里的「保存网格资源」，否则网格不会落盘。

**Q：改完路网怎么保存？**
A：Ctrl+S 存场景即可。路网数据存在场景里的 `TDRoadNetwork` 组件上，网格存在 `.asset` 里 —— **两者都要进版本库**。

**Q：`Road_OldBackup` 还在场景里？**
A：它在测试场景里被**禁用**了，留作对照。确认新路没问题后可以直接删掉。

## 九、文件清单

|---|---|

# 单位状态机（2026-11-08）

本文把当前代码中的敌人、战士、公民、炮台与小队状态机整理成可读版本，并与 `Assets/Script/Unit/` 下的实现对应。
最后一次核对：Unity 6000.0.39f1，编译 0 error / 0 warning，EditMode 95/95 通过（2026-11-15）。

## 1. 统一的数据指针

每个单位身上都可以有 `UnitTargetState`（没有时由 Brain 在 `Awake` 自动补挂），保存两个 `Transform`：

| 指针 | 含义 | 写入时机 |
|---|---|---|
| `ChaseTarget` | 正在尝试靠近的目标 | 追击移动的那一帧写入 |
| `LockTarget` | 正在尝试攻击的目标 | 进入攻击范围并执行攻击的那一帧写入 |

规则：

1. **互斥**：追击时只写 `ChaseTarget` 并清 `LockTarget`；攻击时只写 `LockTarget` 并清 `ChaseTarget`。
2. **清空**：丢失目标、目标死亡、超出拴绳、回到 Idle/巡逻/驻守/修建、单位死亡时，两个指针都清空。
3. **只读展示**：开发者模式单位表（F3）只读取这两个指针，不负责维护。
4. **空安全**：指针目标是 Unity 对象，销毁后读取自动得到 `null`，数据表显示 `-`。

## 2. 敌人 EnemyBrain

```
                 ┌──────────── 无目标 ────────────┐
                 ▼                                │
   ┌──────────┐  搜索(0.25s)  ┌────────┐  未到达  │
   │   Idle   │──────────────▶│ Patrol │─────────┘
   └──────────┘               └────────┘
        │ ▲                         │
 发现目标│ │丢失/超拴绳               │发现目标
        ▼ │                         ▼
   ┌──────────┐  射程外        ┌──────────┐
   │  Chase   │───────────────▶│  Attack  │
   └──────────┘   进入射程      └──────────┘
```

- **Idle**：丢失目标当帧或到达巡逻点时停下（`Halt` + 暂停）；没有巡逻点则把移动交还路线跟随。
- **Patrol**：朝 `patrolGoal` 移动；到达阈值 0.5m 后回 Idle。
- **Chase**：`MoveTo` 目标位置，写 `ChaseTarget`。
- **Attack**：进入 `GetAttackRange()` 后暂停移动、执行能力，写 `LockTarget`。
- **搜索**：每 0.25s 用 `UnitRegistry.FindNearestHostile` 在感知范围（模板 `perceptionRange`，默认 7）内找最近敌对单位。
- **目标丢失**：先回到 Idle 停留一帧，下一帧重新判定（仍无目标则 Patrol），避免同一帧内状态跳变。
- **拦截**：`interceptEnabled` 默认 `false`。关闭时不响应 `UnitEvents.InterceptRequested`，不会转火拦截者，也不会原地待命；开启后恢复旧逻辑（接受范围内转火、超出 20m 或拦截者死亡解除）。

## 3. 战士 WarriorBrain

```
玩家命令? ──是──▶ Move / Attack（命令优先）
   │否
   ▼
Idle ──4m 内发现敌人──▶ Chase ──进入射程──▶ Attack
  ▲                        │                  │
  └──── Return ◀── 目标丢失/超 14m 拴绳 ──────┘
```

- **State**：`Idle / Move / Chase / Attack / Return`。
- **玩家命令优先**：`UnitCommander.HasOrder` 为真时只执行命令，不跑个体索敌。
  - `Move`：清空指针，向槽位移动；距目标 ≤ 0.6m 时清命令、把驻守点更新为当前位置并停下。
  - `Attack`：取命令目标；目标无效则清命令回驻守；射程内攻击、否则追击。
- **个体 AI**：无命令时在 `detectRange = 4m`（2026-11-08 由 10 下调）内找敌人；发现后追击，进入接战距离（双方射程较小者）后攻击。
- **拴绳**：目标距驻守点超过 `leashRange = 14m` 时放弃，清空指针并返回驻守点。
- **指针**：`Chase` 写追逐、`CheckAttack` 写锁定；`Guard`/`Return`/`Idle`/死亡清空。
- **拦截**：`interceptEnabled` 默认 `false`，发现目标只锁定不请求拦截；显式开启后恢复原有请求/释放逻辑。

## 4. 公民 CitizenBrain

优先级：**友方建筑（废墟优先） > 索敌 > Idle**。

```
Idle ──搜索(0.25s, 2m)──┬── 废墟 ──▶ MoveToRepair ──▶ Repair（推进建造进度）
                        ├── 已建成 ─▶ MoveToGarrison ──▶ 进驻并销毁自身
                        └── 敌人 ───▶ Chase ──进入射程──▶ Attack
```

- **State**：`Idle / MoveToRepair / Repair / MoveToGarrison / Chase / Attack`。
- **修建/进驻时**：清空追逐/锁定指针（建筑不是攻击目标）。
- **索敌时**：与战士相同，追击写 `ChaseTarget`、攻击写 `LockTarget`。
- **死亡或被销毁**：清空建筑目标、敌人目标与两个指针。

## 5. 炮台 UnitTurretBrain

- **State**：`Idle / Attack`（由 `StateName` 按是否有目标输出）。
- 不移动，每 0.25s 在攻击范围内找最近敌人；有目标写 `LockTarget`，目标死亡或走出射程时清空并立即重搜。
- 没有 `ChaseTarget`。

## 6. 小队 Squad / SquadBrain

小队是运行期对象（`SquadRegistry` 创建，不写场景），成员通过 `UnitCommander` 接收槽位命令。

```
Selector
  ├─ Sequence[ 集火目标存在 ]          → Engaging
  ├─ Sequence[ 移动命令存在 ]          → Moving（全部到达后完成）
  ├─ Sequence[ 扫描到敌人 ]            → Attack(敌人) → Engaging
  └─ Idle                             → Idle
```

- **SquadState**：`Idle / Moving / Engaging`。
- **Tick 顺序**：剔除死亡成员 → 移动到达判定 → 死亡目标清理 → 每 0.25s 扫描敌人 → 行为树。
- **自动接敌范围**：成员中最大的 `IPerceptionSource.PerceptionRange`，都没有时回退 6m；以小队质心为圆心。
- **移动槽位**：`FormationLayout` 计算 `Line / Column / Grid` 槽位，可选 NavMesh 采样；每个成员收到独立的 `Move` 命令。
- **集火**：`Squad.Attack` 给全部成员下发 `Attack` 命令；目标死亡后 `CompleteOrders` 清空命令并回 Idle。
- **成员变化**：加入新小队会从旧小队移除；死亡成员在 Tick 中剔除并重排槽位；解散清空成员的小队编号与命令。

## 7. 追逐/锁定指针时序表

| 情形 | ChaseTarget | LockTarget |
|---|---|---|
| 追击移动 | 目标 | 空 |
| 进入射程并攻击 | 空 | 目标 |
| 丢失目标 / 目标死亡 | 空 | 空 |
| 超拴绳放弃 | 空 | 空 |
| Idle / Patrol / 驻守 / 修建 | 空 | 空 |
| 玩家移动命令执行中 | 空 | 空 |
| 单位死亡 | 空 | 空 |

## 8. 拦截关闭与恢复

- 默认：`WarriorBrain.interceptEnabled = false`、`EnemyBrain.interceptEnabled = false`，战士不请求拦截、敌人不转火。
- 代码路径完整保留；需要恢复时在 Inspector 勾选两个开关，或在测试中用反射/序列化字段置 `true`。
- `InterceptStateTests` 显式开启开关验证旧行为，另有默认关闭的回归测试。

## 9. 民兵感知 10 → 4 的影响

- `Warrior_Guard.asset.perceptionRange = 4`，`Warrior_Guard.prefab` 的 `WarriorBrain.detectRange = 4`，代码默认也是 4。
- 只影响**自动索敌**；玩家下达的攻击命令仍会执行，不受 4m 限制。
- 拴绳仍是 14m，进入战斗后追击范围不变；但单位更少主动进入战斗，符合“士兵是宝贵资源”的设计。
